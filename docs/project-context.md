# Project Context

## Purpose

Template for AI-assisted software development with Claude Code.

## Tech Stack

- Node.js 22 LTS
- Python 3.12
- uv
- Docker
- GitHub Actions

## Project Structure

- .claude/ - Claude Code commands
- .github/ - GitHub configuration
- docs/ - documentation
- scripts/ - automation
- src/ - source code
- tests/ - tests

## Development Commands

Setup:
make setup

Test:
make test

Clean:
make clean

## Environment

Copy .env.example to .env.

Never commit secrets.

## Workflow

1. Understand project context.
2. Create a plan.
3. Implement changes.
4. Review code.
5. Run tests.
6. Commit changes.

## Constraints

- Avoid unnecessary dependencies.
- Prefer maintainable solutions.
- Keep documentation updated.
