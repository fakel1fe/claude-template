## Claude Code Workflow

Recommended development flow:

1. `/analyze` — inspect the project.
2. `/plan` — create an implementation plan.
3. Implement approved changes.
4. `/review` — review code quality.
5. `/security` — perform a security review.
6. `/test` — run available tests.
7. `/commit` — prepare a commit message.

See `CLAUDE.md` for project instructions.
